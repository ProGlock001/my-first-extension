# Copy-Paste Meter

**Автор:** Бабаш Дмитрий Русланович, группа M3111

**Репозиторий:** https://github.com/ProGlock001/my-first-extension

## Описание

Copy-Paste Meter — расширение для Visual Studio Code, которое показывает, какая часть кода
в открытом файле скопирована из буфера обмена, а какая написана вручную.

Расширение запоминает происхождение каждого символа: набран с клавиатуры, вставлен
или был в файле ещё до начала отслеживания. Если код удалить, он перестаёт учитываться,
поэтому статистика соответствует тому, что сейчас реально находится в файле.

## Возможности

- **Процент в строке состояния.** Справа внизу отображается, например,
  `35% скопировано  65% своё`. При доле скопированного 50% и выше индикатор подсвечивается.
- **Подробная подсказка.** При наведении на индикатор видно количество символов каждого типа.
- **Статистика файла** — команда `Copy-Paste Meter: Показать статистику файла`
  (или щелчок по индикатору).
- **Подсветка скопированного кода** — команда `Copy-Paste Meter: Подсветить скопированный код`
  выделяет вставленные фрагменты оранжевым фоном. Повторный вызов выключает подсветку.
- **Сброс статистики** — команда `Copy-Paste Meter: Сбросить статистику файла`.
- **Настройка** `copyPasteMeter.pasteThreshold` (по умолчанию 30): сколько непробельных
  символов, появившихся за одну правку, считать вставкой, даже если она сделана не через Ctrl+V
  (контекстное меню, перетаскивание).

## Как определяется скопированный код

1. Расширение переопределяет сочетание **Ctrl+V** (Cmd+V на Mac): перед стандартной
   вставкой ставится отметка, и весь вставленный текст считается скопированным.
2. Если за одну правку появилось больше `pasteThreshold` непробельных символов,
   фрагмент тоже считается скопированным.
3. Всё остальное считается написанным вручную.

Пробелы, табуляция и переводы строк при подсчёте не учитываются.

## Использование

1. Откройте любой файл и начните писать или вставлять код.
2. Следите за процентом в строке состояния.
3. Откройте палитру команд (`Ctrl+Shift+P`) и введите `Copy-Paste Meter`, чтобы увидеть остальные команды.

## Сборка и запуск

```bash
npm install
npm run compile
```

Нажмите `F5` в VS Code — откроется окно Extension Development Host с расширением.

Упаковка в `.vsix`:

```bash
npm install -g @vscode/vsce
vsce package
```

## Ограничения

- Статистика хранится в памяти и сбрасывается при закрытии файла или перезапуске VS Code.
- Текст, который уже был в файле при открытии, относится к категории «до отслеживания».
